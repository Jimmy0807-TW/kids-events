# 親子活動清單

每天自動收集全台適合 6～8 歲孩子、每人 1,000 元以內的親子活動，整理成手機可看的網頁，每週用 LINE 推播給家人。

- **網頁**：https://jimmy0807-tw.github.io/kids-events/
- **更新時間**：每天台灣時間晚上 7 點多自動更新
- **LINE 週報**：每週四（可在設定改）

## 日常使用

| 想做的事 | 怎麼做 |
|---|---|
| 看活動 | 開網頁。上方可選地區、縣市、「這個週末」「本週新增」「可報名」等篩選 |
| 跟家人討論 | 用 **#編號**（例如「#12 要不要報？」）。編號每次更新會重排，以同一次更新為準 |
| 標記想去／已報名 | 按卡片上的按鈕。**只存在你這支手機的瀏覽器**，不會公開，也不會同步到其他裝置 |
| 排除這場 | 按「排除這場」→ 開啟 GitHub 頁面 → 按綠色「Create」送出 → 約 1～2 分鐘後消失 |
| 排除整個系列 | 按「排除系列」→ 確認要擋的文字 → 送出。名稱含這段文字的活動之後都不會出現 |
| 恢復 | 網頁最下方「已排除的活動」→ 按「恢復」送出 |
| 用打字的方式 | 在 GitHub 手機 App 的 Issues 新增一則，標題寫「排除 12 15」「排除系列 故事屋」「恢復 小丑魚」 |
| 改條件 | 修改 [`config.yml`](config.yml)（年齡、價格、常用地區、來源開關、LINE 週報星期） |
| 立刻更新 | GitHub → Actions →「更新親子活動」→「Run workflow」 |

> 排除需要登入 GitHub（你本人）。別人開的 Issue 系統會忽略。

## 分級

1. **① 公家機關**：政府、公立館所、圖書館舉辦
2. **② 500 元以下**：民間活動，免費或最低票價 ≤ 500 元
3. **③ 500～1,000 元**
4. **④ 價格未標示**：需點進去確認

排序：等級 → 非長期優先 → 日期由近到遠。超過 1,000 元一律不收。

## LINE 推播設定（一次性）

1. 到 <https://entry.line.biz/> 用你的 LINE 登入，建立「LINE 官方帳號」（免費方案）。
2. 進入 LINE Official Account Manager →「設定」→「Messaging API」→ 啟用，建立一個「服務提供者」（名稱隨意）。
3. 到 <https://developers.line.biz/console/> → 點進剛建立的頻道 →「Messaging API」分頁 → 最下方「Channel access token (long-lived)」→「Issue」→ 複製。
   **這組代碼不要貼在任何對話或檔案裡。**
4. 回到 GitHub 這個程式庫 → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
   - Name：`LINE_CHANNEL_ACCESS_TOKEN`
   - Secret：貼上剛剛複製的代碼 → **Add secret**
5. 「Messaging API」分頁上方有 QR Code，你和家人掃描加好友。
6. 建議在 Manager 的「回應設定」關閉「自動回應訊息」。
7. 測試：GitHub → Actions →「更新親子活動」→「Run workflow」→ 勾選「立刻送出 LINE 週報」→ 執行。

免費方案每月 200 則，**每位好友收到一則算一則**。3 位家人 × 每週 1 則 ≈ 每月 15 則，加上報名提醒仍很足夠。

## 程式結構（給 AI 看）

- `scraper/sources.py`：各來源抓取，新增來源就加一個函式並登記到 `SOURCES`
- `scraper/common.py`：日期、價格、年齡、縣市解析
- `scraper/build.py`：篩選、分級、去重、編號，輸出 `data/events.json`
- `scraper/issues.py`：處理排除／恢復 Issue
- `scraper/line_push.py`：LINE 週報與報名提醒
- `site/index.html`：網頁
- `.github/workflows/update.yml`：每天自動執行、處理 Issue、部署網頁
- 去重規則：完整名稱（去標點、去「第N場」與場次時間）＋縣市相同才合併，不再用名稱前 18 字
